Tool Box — App Store 其他审核字段核对表
=========================================
日期：2026-09-27
生成依据：项目代码实际实现（非猜测）
用途：随主审核回复一起核对 App Privacy 问卷、广告、年龄分级等字段

一、App Privacy（隐私问卷）数据收集项
====================================
依据代码确认 App 实际收集的数据，问卷须如实勾选。

| 数据类别 | 是否收集 | 说明 / 代码依据 |
|---|---|---|
| 联系信息-邮箱 | 是 | 登录后存储（user_profile.email，Supabase users 表） |
| 联系信息-姓名(昵称) | 是 | 编辑资料可填昵称 displayName，最长24字 |
| 用户ID | 是 | auth.users.id / public.users 主键 |
| 用户内容 | 否(本地) | 出行清单/备忘录存本地 Isar，不上传、不分发 |
| 广告数据(投放展示) | 是 | AdMob banner/rewarded/interstitial |
| 其他诊断数据 | 是 | 埋点 app_events（track-event Edge Function） |
| 其他-设备标识(哈希) | 是 | IDFV/ANDROID_ID 经 SHA-256 哈希后上报（device_id.dart） |
| 精确位置 | 否(不收集上传) | 指南针仅在本机读取 GPS，不上传 |
| 购买历史 | 否(上报) | 内购仅本地 StoreKit 校验，云端不写支付信息(方案A) |

问卷填写建议：
1. 勾选上面「是」的类别；未收集的类别不要勾选。
2. 「该数据是否与用户身份关联」：邮箱/昵称/用户ID 关联；埋点事件经
   user_id 关联（部分匿名）；哈希设备ID 用于游客识别。
3. 「该数据是否用于追踪」：AdMob 广告数据涉及追踪，需如实声明。
4. 隐私政策 URL 必须指向你 Github Pages 的隐私政策页，并在问卷中列出。

二、广告与追踪（关键）
======================
| 字段 | 状态 | 说明 |
|---|---|---|
| NSUserTrackingUsageDescription (IDFA弹窗) | 未配置 | Info.plist 无此项 → App 不请求 IDFA；广告走非个性化/由 UMP 决策 |
| UMP 同意管理 | 已接入 | consent_helper.dart，GDPR/EEA/UK 地区合规 |
| SKAdNetwork | 已配置 | Info.plist 含 SKAdNetworkItems |
| GADApplicationIdentifier | 已配置 | ca-app-pub-4627610691741188~4914070814 |
| app-ads.txt | 已准备 | doc/app-ads.txt |

注意点：
- 因不请求 IDFA，App Privacy 问卷「设备ID-广告标识(IDFA)」项无需勾选；
  但「广告数据-投放展示」仍需如实勾选。
- 如需后续接入 IDFA 追踪，则必须补 NSUserTrackingUsageDescription 文案，
  并重新生成新版本提交（2.1 会要求录屏含权限弹窗）。

三、年龄分级（有广告）
======================
| 字段 | 建议值 | 说明 |
|---|---|---|
| 年龄分级 | 4+ | 工具类App，无暴力/血腥/色情/毒品/粗口/赌博，仅第三方广告 |
| 是否专为儿童设计 | 否 | 不要勾选「儿童类」，否则 COPPA 会禁用 AdMob 广告 |
| EULA 最低年龄 | 可选建议 13+ | 在隐私政策/用户协议声明，规避未成年人风险，不影响分级 |
